LAST SOUL — SITE WEB
======================

Arquivos:
- index.html — estrutura da página
- style.css — visual, responsividade e animações
- script.js — menu mobile, ano automático e efeitos de entrada

Como abrir:
1. Abra a pasta LastSoul_Web no VS Code.
2. Abra index.html no navegador.
3. Para desenvolvimento, pode usar a extensão Live Server.

Observação:
Os retratos dos personagens nesta primeira versão são placeholders estilizados.
Eles podem ser substituídos depois pelos sprites oficiais do jogo.
